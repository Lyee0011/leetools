# 小伊提词器 · 双手机遥控版

用一台手机看稿，另一台手机远程回退或暂停。提词端支持自动滚动、字号与速度调节、镜像，以及黄色重音。打开现有网页即可使用。[打开手机提词器](https://xcnlz6stphqd.feishuapp.com/app/app_17cc7wudm9y)

1. 在提词手机上粘贴文稿，进入提词画面，点「开启双机遥控」，记下两位配对码。
2. 在遥控手机上打开同一个网页，点「用这台手机遥控另一台」，输入配对码。
3. 遥控页默认上下两个大按钮。上键回退约 5 秒并自动继续播放，下键暂停或继续。

两台手机需要联网并保持页面在前台，可以使用不同的 Wi-Fi 或移动网络。稿件和显示设置保存在当前浏览器，双机连接只同步按键指令、播放状态和进度。手写 `**重音**` 或粘贴支持的加粗文字，可在提词时显示黄色粗体。

## 源码

目录收录妙搭手机版的核心源码，取自已用于发布的源码提交 `fd3812c`。

- `client/` 包含提词、遥控、稿件重音处理和样式。
- `server/modules/remote/` 包含 NestJS 配对、状态同步与按键确认。
- `shared/remote.ts` 定义提词端与遥控端共用的数据结构。

源码适用于妙搭 React + NestJS 全栈模板。接入时，将 `client/`、`server/` 和 `shared/` 中的文件放到模板的同名目录，由 `client/src/app.tsx` 导出 `Teleprompter`，加载 `client/src/index.css`，并在服务端 `AppModule` 中将 `RemoteModule` 注册在平台页面的兜底路由之前。遥控依赖平台提供的共享 `CACHE_MANAGER` 及其路由、CSRF 配置。安装和部署使用自己的妙搭项目设置。
