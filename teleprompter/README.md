# 手机提词器 · 双机遥控版

**用手机浏览器直接打开即可使用，无需安装或登录。** 一台手机就能自动滚动提词，第二台手机可以当遥控器。[打开手机提词器](https://xcnlz6stphqd.feishuapp.com/app/app_17cc7wudm9y)

## 一台手机怎么用

1. 在手机浏览器打开网页，把口播稿粘贴到「你的文稿」。首次试用也可以用页面自带的示例。
2. 在「播放设置」调整字号和速度，点「开始提词」。播放时点一下屏幕即可暂停或继续。

想强调某几个字，可以写成 `今天只讲**一个技巧**`。提词时，「一个技巧」会显示为黄色粗体。

## 两台手机怎么配对

1. **看稿的手机**点「开始提词」，在提词画面点「开启双机遥控」。屏幕上会显示两位配对码。
2. **当遥控器的手机**打开同一个网页，点「用这台手机遥控另一台」，输入两位数字，再点「连接提词手机」。
3. 显示「已连接」后，默认上键回退约 5 秒并继续播放，下键暂停或继续。

两台手机都要联网，并保持页面亮着、留在前台。连接断开时，回到提词页面重新配对。录完可在提词手机点「显示控件」，再点「结束遥控」。

稿件和显示设置保存在当前浏览器。遥控连接只同步按键、播放状态和进度。配对码只给正在帮你遥控的人。

## 让 AI 一步一步带你用

把下面这段复制到你常用的 AI 聊天工具里，再告诉它你有一台还是两台手机。

```text
我第一次用手机提词器，请用简单中文一步一步带我操作。
工具网址 https://xcnlz6stphqd.feishuapp.com/app/app_17cc7wudm9y

先问我手边有一台还是两台手机。只有一台，就教我粘贴稿子和开始提词。
有两台，就告诉我哪台看稿、哪台遥控，再带我完成配对和试按暂停。
每次只给我一到两步，用网页里实际显示的按钮名。等我说做完再继续。
如果找不到按钮，让我先描述当前画面。用示例稿练习即可，无需提供我的正式稿件或配对码。
```

如果想让 AI 帮你准备稿子，也可以说「请把这段口播稿拆成适合手机阅读的短段落，保留原意，用 `**` 标出少量需要重读的词。」把整理后的稿件复制到提词器即可。

## 源码

目录收录妙搭手机版的核心源码。日常使用可直接打开上方网页。以下说明供想自行部署的开发者参考。

- `client/` 包含提词、遥控、稿件重音处理和样式。
- `server/modules/remote/` 包含 NestJS 配对、状态同步与按键确认。
- `shared/remote.ts` 定义提词端与遥控端共用的数据结构。

源码适用于妙搭 React + NestJS 全栈模板。接入时，将 `client/`、`server/` 和 `shared/` 中的文件放到模板的同名目录，由 `client/src/app.tsx` 导出 `Teleprompter`，加载 `client/src/index.css`，并在服务端 `AppModule` 中将 `RemoteModule` 注册在平台页面的兜底路由之前。遥控依赖平台提供的共享 `CACHE_MANAGER` 及其路由、CSRF 配置。安装和部署使用自己的妙搭项目设置。
