## 发现与处理

| 级别 | 触发条件与影响 | 修复与证据 |
|---|---|---|
| P1 | 带合法本机令牌提交 JSON `null`，旧版 `/api/retry` 触发未处理异常，整个服务退出 | 请求体必须是非空 JSON 对象；统一捕获路由异常。旧版复现为进程退出 1，新版返回 400 且继续响应 |
| P1 | HLS 丢失一个分段，旧版仍能生成可播放文件并报告完成；失败后猜测合并分轨也可能掩盖不完整下载 | 要求缺失分段立即失败，只有下载进程成功退出且成品通过音画检查才完成。相同生成样本在基线得到 `done`，修复后得到 `error`；完整样本仍成功 |
| P1 | Windows 环境探测可能先执行 PATH 中的程序，或仅凭文件存在判定组件可用 | 使用本目录清单中固定 SHA-256 验证后的程序。测试替换/缺失字节，确认会拒绝；导入 Windows 服务源码不会执行 PATH 探测 |
| P2 | 首次安装依赖操作者判断端口，容易把旧进程或另一安装目录的页面当成安装成功 | 人与 Agent 共用安装入口；核对应用 ID、源码构建、安装实例和组件状态，返回实际 URL、PID、目录及日志 |
| P2 | 本轮新安装测试中，中文、空格及方括号路径触发 PowerShell 下载、启动与辅助程序编译失败；输出管道继承还会让 Agent 收不到完成结果 | 下载和编译使用 .NET 字面路径；服务通过隐藏的 ShellExecute 进程启动。无配置、无组件的新目录完成下载、校验和辅助程序编译；首次与再次启动返回同一 PID 和 URL |
| P2 | 浏览器资源选择可能混淆独立视频与媒体分段；未完成检查的播放列表不应被选中 | 排除分段和单音轨类型，检查播放列表内容，多播放器或无关资源保持失败。实站复测发现的 DASH `.m4v` 分段回归已修复，完整下载再次通过 |
| P2 | 临时浏览器启动、断开和上级进程退出缺少完整超时与清理边界 | 增加 CDP 请求超时、IPC 取消及上级断开清理。正常完成、空页面、受保护播放器及上级断开测试通过，未留下新建资料目录 |
| P2 | 失败结果、目录写入和重复任务可能造成误报或资源争用 | 配置原子写入并报告失败；每个下载使用独立临时目录；最多三个并发任务；不覆盖已有同名文件 |

## 保留的边界

这是针对应用及安装流程的一轮审查，不是零故障或全部网站兼容的证明。

- 实测环境是现有 Windows 11 x64 电脑上的干净目录，不是另一台电脑或新建的普通用户账号。Windows 10、ARM64、受企业策略管理的设备、特殊代理和安全软件组合未在本轮实机验收；发行目标仍为 Windows 10/11 x64。
- 本轮没有重新完整验证所有 YouTube、B站、小红书和央视频样本。央视频保留协议与传输完整性测试，历史实站结果单独记录。网站、接口、代理与风控变化仍可能导致失败。
- 音画和容器检查不是逐帧解码，不能发现所有花屏、错误时长或原站内容缺损；通用网站也没有统一的原站文件校验和。
- 运行组件保持已有固定版本，本轮验证其校验和和调用方式，未审计第三方二进制内部，也未做全量 CVE 扫描。后续更新需同时维护固定版本、校验和、许可说明并回归测试。
- 临时浏览器用独立资料目录和请求过滤降低风险，不能视为操作系统级网络沙箱。保持浏览器更新，不将本工具作为远程公共服务。
- 登录、验证码、DRM、付费、私密内容和无法确定主视频的复杂页面仍可能不支持。
