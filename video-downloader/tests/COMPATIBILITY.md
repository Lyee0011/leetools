## 自动化检查

- Windows 完整 smoke 与 HTTP Host / Origin / POST 令牌 / 请求体限制检查通过。
- 公网地址边界、原有站点排除、失败类型判断、HLS 主播放列表选择、多资源歧义检查通过。
- 浏览器成功、空网页超时、受保护播放器三种路径均会关闭临时浏览器并清理资料目录。
- 下载时需来源请求头的动态 MP4 样本通过；未读取个人资料或导出 Cookie。
- TS 内容误命名为 `.mp4` 的样本完成无重编码封装，FFmpeg 确认真正的 MP4 容器和音画；无声样本不会被标记为完成。
- 同时提交 HLS 与 DASH 网页时，识别按队列串行执行，下载可以继续并行。

## 保留的限制

- 登录、验证码、DRM、付费与私密内容不会自动处理。
- 没有可见播放器、需要复杂手动操作、跨域嵌入或多个无法确认主视频的页面仍可能失败。
- 新流程只接收公开 HTTP(S) 页面和播放资源；本机、局域网以及非常规端口不进入浏览器解析。
- 识别得到的来源和浏览器标识可以复用；账号 Cookie 不会跟随浏览器补充流程传给下载器。
- 页面、播放接口、地区限制和代理节点会变化，失败时优先使用具体视频页的最新分享链接重试。
