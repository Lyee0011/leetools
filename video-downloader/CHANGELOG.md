# 发布记录

## v1.0.3 · 2026-09-24

- 修复部分 B站视频主下载节点超时后反复失败的问题：通过本地 yt-dlp 插件保留原站 DASH 备用地址，优先同等清晰度的标准 CDN，并检查实际可下载性。
- B站代理请求失败时自动尝试直连并重新获取地址；不使用 B站浏览器登录状态，不影响其他站点的代理配置。
- 区分 B站接口连接失败和视频节点连接失败，失败后正确显示“失败”阶段。
- 增加真实 yt-dlp 的坏地址切换回归测试；完整下载问题视频并通过音视频校验。

## v1.0.2 · 2026-09-21

- 调整首页文案和交互，让第一次打开的人更容易理解怎么用。
- 增加“小伊工具箱”标识、本地运行说明、空记录提示和可展开的运行状态。
- 将完成、失败、重试、打开文件等状态改成更口语的表达。
- 保留原有蓝白配色，避免影响识别和可读性。

## v1.0.1 · 2026-09-21

- 移除首页平台标签中的“央视频”，保留后端的央视频下载支持。
- 增加“清理历史记录”按钮，只清除界面中的已完成/失败记录，不删除磁盘文件，也不打断进行中的任务。

## 仓库目录整理 · 2026-09-20

- 仓库根目录只保留 `video-downloader/`，每个小工具单独一个目录。
- 说明、许可、忽略规则和配置集中到工具目录；重复的仓库级说明合并进本工具文档。
- `.github/` 移到工具内部作为配置参考，GitHub 自动检查与 Issue 模板不再自动生效；本地测试脚本仍可使用。
- 已发布的 v1.0.0 下载包及其校验值保持不变，本次未修改下载器运行代码。

## v1.0.0 · 2026-09-20

首次发布到 `Lyee0011/leetools` 的 `video-downloader/` 子目录。

- 提供独立 Windows x64 ZIP，完整解压后双击启动；首次联网自动准备固定版本的运行组件，不需要 npm、Python 或管理员权限。
- 启动窗口显示组件准备步骤；保留 SHA-256 校验和失败日志。
- 新增停止入口，只停止当前目录的空闲实例，不关闭其他 Node 或浏览器进程。
- 补齐快速开始、首次联网要求、更新与卸载、平台限制、登录状态说明、反馈入口和第三方许可。
- 修正 yt-dlp Windows 可执行版的许可描述；自有 MIT 代码与第三方 GPLv3+ 组件分别说明。
- 源码包不带运行组件、个人配置、Cookie、浏览器资料、下载记录或视频文件。原本地 Git 历史不导入公开仓库。

验证范围：Windows x64 干净目录的组件下载与校验、本地生成音视频的下载和完整性检查、临时浏览器解析及清理、HTTP 接口边界、首次启动/重复启动/停止，以及最终 ZIP 解压启动。首次发布的云端验证已通过，见 [GitHub Actions 历史记录](https://github.com/Lyee0011/leetools/actions/runs/35500647857)。

本次没有重新实测所有外部平台。历史样本及日期见 [兼容性记录](tests/COMPATIBILITY.md)。网站改版、登录/验证码、地区与网络限制仍可能导致失败；Windows 10 和 ARM64 未在本机实测，ARM64 不提供支持。运行组件使用固定版本，不承诺始终为上游最新版。
