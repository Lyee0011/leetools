# 发布记录

## v1.0.0 · 2026-09-20

首次发布到 `Lyee0011/leetools` 的 `video-downloader/` 子目录。

- 提供独立 Windows x64 ZIP，完整解压后双击启动；首次联网自动准备固定版本的运行组件，不需要 npm、Python 或管理员权限。
- 启动窗口显示组件准备步骤；保留 SHA-256 校验和失败日志。
- 新增停止入口，只停止当前目录的空闲实例，不关闭其他 Node 或浏览器进程。
- 补齐快速开始、首次联网要求、更新与卸载、平台限制、登录状态说明、反馈入口和第三方许可。
- 修正 yt-dlp Windows 可执行版的许可描述；自有 MIT 代码与第三方 GPLv3+ 组件分别说明。
- 源码包不带运行组件、个人配置、Cookie、浏览器资料、下载记录或视频文件。原本地 Git 历史不导入公开仓库。

验证范围：Windows x64 干净目录的组件下载与校验、本地生成音视频的下载和完整性检查、临时浏览器解析及清理、HTTP 接口边界、首次启动/重复启动/停止，以及最终 ZIP 解压启动。公开仓库的持续检查见 [GitHub Actions](https://github.com/Lyee0011/leetools/actions/workflows/windows-smoke.yml)。

本次没有重新实测所有外部平台。历史样本及日期见 [兼容性记录](tests/COMPATIBILITY.md)。网站改版、登录/验证码、地区与网络限制仍可能导致失败；Windows 10 和 ARM64 未在本机实测，ARM64 不提供支持。运行组件使用固定版本，不承诺始终为上游最新版。
