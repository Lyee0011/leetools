# leetools

- This is a public collection of small tools. Each subdirectory is an independent tool.
- Before changing `video-downloader/`, read its `AGENTS.md`, `README.md`, and `INSTALL.md`.
- Never commit credentials, `.env` files, personal configuration, browser profiles, cookies, runtime binaries, generated media, or local test artifacts.
- Keep runtime downloads pinned to immutable versions and SHA-256 hashes.
- Releases contain the reviewed source and launchers; runtime components are downloaded by the user. Do not add third-party binaries to a release without separately completing their redistribution and corresponding-source requirements.
- A change to a tool must be tested in that tool's directory. Keep the root index and download links accurate.
- Commit with the maintainer's GitHub noreply address, not a personal email address.
