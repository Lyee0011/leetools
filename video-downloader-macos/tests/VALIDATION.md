# 验证记录

日期：2026-09-24。开发环境：Windows，测试对象是独立的 `video-downloader-macos/`，原 Windows 目录不修改。

## 当前状态

**macOS 预览版，尚未通过 Mac 实机验收。** “已通过”只指下面明确列出的开发主机检查，不代表 Mac 双击启动、系统权限或各网站下载已成功。

## 开发主机已通过

- JavaScript 语法与源码测试；URL 边界、任务公开字段、安全参数。
- 固定依赖校验逻辑；错误架构、缺失和篡改文件被拒绝，导入服务不会执行 PATH/Homebrew/Python 探测。
- 文件夹适配测试：中文、空格和方括号；根目录 `/`；用户取消；系统权限错误；命令参数按数组传递，不作为 shell 代码。
- HTTP 安全测试：Host、来源、令牌、Content-Type、畸形 JSON、请求体上限、历史清理。
- 停止接口：缺令牌拒绝、错误实例拒绝、正确实例空闲时退出；停止资格逻辑拒绝正在运行的任务。
- 央视频解析与传输单元测试；通用浏览器发现策略单元测试。
- Mac 源码的主机下载回归：使用经过原清单校验的 Windows FFmpeg/yt-dlp，只生成并传输临时本地视频；缺失 HLS 分段失败、完整 HLS 转为 MP4、已有文件不覆盖、本地检查不访问网络播放列表、三任务上限通过。这项**没有执行 Mac 二进制**。
- Bash 脚本语法在 Git Bash 中检查；不等于 macOS 系统 Bash 实际安装测试。
- Node 两个架构的归档哈希与官方 SHASUMS256.txt 对照；解出的可执行文件另行固定 SHA-256。
- yt-dlp Mac 通用二进制已下载，哈希与固定 GitHub Release 资产摘要一致。
- FFmpeg 9.0.2 两个架构 ZIP 已下载，分别与上游 SHA-256 文件对照；解出的二进制另行固定哈希。
- Mach-O 文件头静态检查：Node 对应 arm64/x64，最低系统 11；FFmpeg 对应 arm64/x64，最低系统 12；yt-dlp 外层含 arm64/x64。动态库引用限系统路径。此项不是执行或签名验收。
- 本项目把最低系统设为 macOS 13；旧系统未承诺兼容。
